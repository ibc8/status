# Статус сервисов

Публичная страница статусов FreeTurn, Mieru и бесплатной подборки. Сайт не содержит подписок, ключей, адресов клиентов или конфигураций.

GitHub Actions раз в пять минут получает обезличенный JSON от 177 и публикует статический сайт на GitHub Pages. История проверок хранится в `history.json` за последние 90 дней; прошлые даты без измерений остаются серыми. Если 177 недоступен, системы получают состояние «Нет данных». Браузер также скрывает устаревшее состояние через 15 минут.

Экспортёр `server/status_export.py` запускается на 177 отдельным systemd-сервисом. Он отдаёт только `/status.json` на HTTP-порту 80; проверяет FreeTurn и Mieru по состоянию процесса и сокета, а подборку — по локальной агрегированной статистике панели. Это не клиентский тест VPN из конкретной сети.

Для публикации включите GitHub Pages с источником **GitHub Actions** в настройках репозитория. Запланированные задачи GitHub Actions могут задерживаться, поэтому страница всегда показывает время последней проверки.
